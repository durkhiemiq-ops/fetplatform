# FET Project Management System

A comprehensive project management and assessment system for the Faculty of Engineering and Technology (FET).

## 🚀 Features

### Core Features
- ✅ **Dashboard** - Real-time statistics and project overview
- ✅ **Project Management** - Create, read, update, delete projects
- ✅ **Task Management** - Create, update, delete tasks with status tracking
- ✅ **Group Management** - Create, update, delete groups
- ✅ **Attendance Tracking** - Mark and manage student attendance
- ✅ **Assessment System** - Rubric-based continuous assessment
- ✅ **Contribution Tracking** - Monitor student contributions
- ✅ **Announcements** - Post and manage announcements
- ✅ **Milestones** - Track project milestones

### Technical Features
- ✅ **Data Persistence** - All data saves to localStorage
- ✅ **Real-time Updates** - UI updates immediately on changes
- ✅ **Activity Logging** - All actions are tracked
- ✅ **Responsive Design** - Works on all screen sizes
- ✅ **Dark/Light Mode** - Using the FET design system
- ✅ **Search & Filter** - Find what you need quickly
- ✅ **Modal Forms** - Clean, intuitive CRUD operations
